# WorkHours Pro 🕒

O **WorkHours Pro** é uma ferramenta web simplificada, mas poderosa, projetada para colaboradores que precisam gerenciar sua jornada de trabalho de forma privada, rápida e eficiente. Desenvolvido inteiramente com tecnologias web nativas, ele foca em simplicidade e privacidade total.

## ✨ Funcionalidades Principais

- **Registro de Ponto Inteligente:** Informe horário de entrada, saída e tempo de pausa. O sistema calcula automaticamente o total trabalhado.
- **Cálculo de Horas Extras:** Configurado por padrão para uma jornada de 7 horas diárias, identificando automaticamente excedentes.
- **Perfil do Colaborador:** Campos dedicados para Nome, Matrícula e Função que personificam seus relatórios.
- **Notas e Observações:** Adicione pequenos lembretes (até 200 caracteres) em cada registro diário.
- **Exportação para Excel (CSV):** Gere relatórios profissionais em formato CSV compatível com Microsoft Excel (configurado para padrões brasileiros com separador `;` e codificação UTF-8).
- **Design Responsivo:** Interface otimizada para computadores, tablets e smartphones usando Tailwind CSS.
- **Privacidade Total:** Seus dados nunca saem do seu computador. Não há servidores externos ou bancos de dados em nuvem envolvidos.

## 🚀 Como Usar

1. **Preencha seu Perfil:** No card "Perfil do Colaborador", insira seu nome, matrícula e função. Esses dados serão usados no cabeçalho dos seus relatórios.
2. **Registre seu Dia:** No formulário "Novo Registro", selecione a data e os horários. Clique em "Salvar Registro".
3. **Gerencie o Histórico:** Você pode editar registros antigos clicando no ícone de lápis ou excluí-los no ícone de lixeira.
4. **Gere Relatórios:** Clique no botão verde "Exportar Excel" para baixar um arquivo consolidado com todos os seus dados.

## 🛠️ Tecnologias Utilizadas

- **HTML5:** Estrutura semântica para melhor acessibilidade.
- **CSS3 (Tailwind CSS):** Estilização moderna e responsiva via CDN.
- **JavaScript (ES6+):** Lógica pura JS para cálculos e manipulação do DOM.
- **LocalStorage API:** Persistência de dados local no navegador.

## 🔒 Segurança e Privacidade

- **Sem Cookies de Rastreamento:** O aplicativo não utiliza cookies para rastrear o comportamento do usuário.
- **Armazenamento Local:** Os dados são gravados exclusivamente no `localStorage` do seu navegador. Isso significa que se você limpar os dados do navegador ou trocar de computador/dispositivo, os dados não serão transferidos automaticamente.
- **Offline First:** O aplicativo funciona perfeitamente sem conexão com a internet após o carregamento inicial.
